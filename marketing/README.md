# Marketing

- `ads/` Meta ads. One folder per build date, each with a `launch.md` to paste from; `ads/shots/` holds the app screenshots they are built on (`scripts/capture-ui.ts`, `scripts/meta-ads.ts`).
- `posts/` Instagram feed posts, one folder per post, named `<date>-<what>`.
- `reels/` 9:16 reels, one folder per reel (`scripts/reel.ts`, `scripts/reel-slams.ts`).
- `briefs/` Prompts and source records for Claude Design: the Instagram and Saturday wrap prompts, the season record and its shareable page.
- `assets/` Reusable images not tied to one post.

No bookie names and no betting words in anything paid. Every number comes off the stored card.
