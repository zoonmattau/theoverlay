# YouTube Shorts: description template

Swap the bracketed bits per Short. Keep the last two lines on every one.

```
[Horse] won at $[price]. We had it at $[our price]. #horseracing #racingtips #punting

Every call, won and lost: theoverlay.com.au/results
18+ only. Gamble responsibly. 1800 858 858
```

For a day's result:

```
[Day]: [+X.X] units from [N] calls. Every one on the results page. #horseracing #racingtips

Every call, won and lost: theoverlay.com.au/results
18+ only. Gamble responsibly. 1800 858 858
```

Title: the hook from the reel, short, e.g. "$17.56 winner at the Gold Coast" or "+47.6 units on Saturday".
Related video: the intro video, or the long video the Short comes from.
