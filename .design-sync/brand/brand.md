# Brand

The Overlay's mark is a square with a rising line inside it. The wordmark is OVERLAY in Archivo Black caps with THE tracked out above. Files are in `brand/`; the card in the Brand group shows each on its ground.

| File | Use |
|---|---|
| `brand/lockup-dark.png` | Horizontal lockup for dark grounds. The site's top bar uses this. |
| `brand/logo-horizontal-dark.png` | The same at print size. |
| `brand/lockup-light-stacked.png` | Stacked lockup for light grounds and square formats. |
| `brand/logo-stacked-light.png` | The same at print size. |
| `brand/mark-onlime-dark.svg` | The mark with a lime line, for dark grounds, favicons, corner marks. |
| `brand/mark-mono-black.svg` | Single colour mark for light grounds and on the lime fill. |
| `brand/mark-mono-white.svg` | Single colour mark for dark grounds and photos. |
| `brand/avatar-1080.png` | Profile picture, 1080 square. |

Rules. Lime `#c6f24e` is the line on dark grounds only; on light grounds the whole mark is ink `#14161a`. Never recolour, stretch, rotate or add shadows. Clear space around the mark is at least the height of the square. Wordmark top left and theoverlay.com.au bottom right on every social graphic.
